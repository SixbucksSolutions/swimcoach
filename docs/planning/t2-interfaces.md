  in the constructor. Keys compare ASCII case-insensitively (api.md 4.3); store a lowercased key column.
  `commitReport` and `stopMilestone` MUST be atomic (`ctx.storage.transactionSync`).

  where the samples map is keyed by the lowercased key. `ReportResult` is
  `PlanResult` with the plan's outcome after commit; A MAY import `planReport` from MVP-03 B's
  module by the frozen name below, and SHOULD stub it in A's own tests until B's PR merges.
